# Suporte

## Antes de pedir ajuda

- Leia o `README.md` e o guia em `docs/DEPLOYMENT.md`.
- Confira a mensagem de erro completa e os logs relevantes.
- Informe o que tentou fazer, o resultado esperado e o resultado observado.
- Se possível, descreva os passos para reproduzir o problema com dados fictícios.

## Ao abrir uma issue

Use o modelo de bug ou solicitação de melhoria. Não anexe senhas, tokens, arquivo `.env`, banco de dados, dados de clientes ou informações pessoais. Remova esses dados de capturas de tela e logs antes de compartilhar.

## Ajuda sobre a implantação

Informe o provedor, o tipo de serviço, o passo da implantação e a mensagem de erro, mas oculte nomes de usuário, senhas, URLs de conexão e outros segredos.
